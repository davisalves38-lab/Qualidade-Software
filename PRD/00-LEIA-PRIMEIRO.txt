O QUE É?
  Site de futebol que centraliza dados dos 20 clubes da Série A do Brasileirão

PARA QUEM?
  • ADMIN: Gerencia todo o sistema
  • INVESTIDOR: Analisa e compara performance dos clubes
  • TORCEDOR: Acompanha seu time favorito

DADOS PRINCIPAIS (POR CLUBE)
  ✓ Posição na tabela
  ✓ Vitórias e derrotas
  ✓ Saldo de gols
  ✓ Melhor jogador do momento
  ✓ Pior jogador do momento
  → Atualização: Semanal (máximo 24h após rodada)

MVP INCLUI
  ✓ 3 Dashboards distintos (Admin, Investidor, Torcedor)
  ✓ Permissões por persona
  ✓ CRUD de dados
  ✓ Sincronização semanal

FASE 2 (T+3 MESES)
  📋 Histórico de temporadas
  📋 Comparação avançada
  📋 Exportação de relatórios
  📋 Notificações em tempo real
  📋 Compartilhamento em redes sociais

FASE 3 (T+6 MESES)
  🚀 Community de torcedores
  🚀 Análises estatísticas avançadas
  🚀 Suporte para Série B
  🚀 API pública
  🚀 Fantasy Football
