# ⚡ Foot Fanatics — Quick Start

**Resumo em 5 minutos para quem tem pressa!**

---

## 🎯 O Que é Foot Fanatics?

Um site que centraliza dados dos **20 clubes da Série A do Brasileirão** e oferece três experiências:

- **Admin:** Gerencia tudo
- **Investidor:** Analisa e compara clubes
- **Torcedor:** Acompanha seu time favorito

---

## 📊 Dados Centralizados

```
POR CLUBE:
├─ Posição na tabela
├─ Vitórias
├─ Derrotas
├─ Saldo de gols
├─ Melhor jogador (Rating 0-10)
└─ Pior jogador (Rating 0-10)

Atualização: Semanal (máximo 24h após rodada)
```

---

## 👥 As 3 Personas

### 1. ADMIN (Sistema Inteiro)
```
┌─────────────────────────┐
│ Atualizar Dados         │
│ Gerenciar Jogadores     │
│ Controle de Usuários    │
│ Monitoramento           │
│ Configuração            │
└─────────────────────────┘
```

### 2. INVESTIDOR (Todos os Clubes)
```
┌─────────────────────────┐
│ Ver Tabela (20 clubes)  │
│ Filtrar/Ordenar         │
│ Análise Detalhada       │
│ Comparar (Fase 2)       │
│ Exportar (Fase 2)       │
└─────────────────────────┘
```

### 3. TORCEDOR (1 Clube)
```
┌─────────────────────────┐
│ Selecionar Clube        │
│ Ver Posição             │
│ Ver Vitórias/Derrotas   │
│ Ver Saldo de Gols       │
│ Ver Jogadores-Chave     │
│ Ver Histórico (Fase 2)  │
└─────────────────────────┘
```
